# Feedback and contributions

Use [GitHub issues](https://github.com/ericqian77/tie-studio-skill/issues) for reproducible
bugs or small, concrete improvements. Include host and OS versions, package version,
download commit, verification result, expected behavior and observed behavior.
For discovery issues, identify whether the intended project Skill was loaded.

Use synthetic examples. Redact personal paths, credentials and private project records;
do not upload complete real workspaces or conversation histories.

This repository contains generated distribution packages. Accepted method and adapter
changes are reconciled in the development source and regenerated with updated manifests.
Contributors do not need access to that source to report issues or propose a change here.
Modified local copies should not be presented as verified official packages. Preserve
contributor attribution and the MIT license when incorporating accepted changes.

Public availability does not establish host acceptance. Cursor's discovery and dialogue
checks remain pending; consult [its acceptance protocol](cursor/ACCEPTANCE.md).
